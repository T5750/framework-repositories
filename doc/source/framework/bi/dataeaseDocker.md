## Installation
### DataEase V3
[https://github.com/dataease/dataease/releases](https://github.com/dataease/dataease/releases)
```sh
sudo -i
# 解压离线安装包
tar zxvf dataease-online-installer-v3.1.0-ce.tar.gz
# 安装
cd dataease-online-installer-v3.1.0-ce
bash install.sh

# 用户名: admin
# 密码: DataEase@123456
```

### DataEase V1
```sh
curl -sSL https://dataease.oss-cn-hangzhou.aliyuncs.com/quick_start.sh | sh
```
- [http://localhost:8000/](http://localhost:8000/)
- User: admin / dataease
